SMS Compliance

LAJEMBO SMS opt-in proof

This page documents the in-app consent flow used before LAJEMBO sends a one-time authentication code by SMS.

How users opt in

  • The user enters their own mobile phone number in the LAJEMBO app.
  • The user must actively check the SMS consent box before requesting a code.
  • The disclosure states that the user agrees to receive one-time authentication codes from LAJEMBO by SMS.
  • The disclosure states that message rates may apply and that this is not consent to marketing messages.
  • The user then taps “Send six-digit code” to initiate the OTP request.

LAJEMBO uses this flow only for authentication, identity verification, and account access. It is not used for marketing or promotional messaging.
